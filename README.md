# 評量作答紀錄

這是可直接部署到靜態網站主機的單頁網頁，沒有建置步驟或額外套件。

## 網頁功能

- 從學生名單試算表載入班級座號。
- 從題目試算表載入卷號與各卷題目數。
- 步驟一、二、三在同一個畫面；班級座號和卷號使用下拉選單。
- 逐題點選 1（答對）或 0（答錯）。
- 每列最多 10 題；題目較多時會自動換列。
- 送出後將每題寫成一列：學生班級座號、卷號、題號、對錯紀錄。
- 同一學生、卷號與題號再次送出時更新既有紀錄，避免重複列。

## 試算表讀取方式

網頁以 Google Visualization 試算表資料來源讀取公開唯讀資料，不需要 Google Sheets API 金鑰。資料仍由瀏覽器直接向 Google 讀取。依 Google 文件，受限制的試算表需要 OAuth 等授權；不要把服務帳戶金鑰或 OAuth 機密放進前端網頁。

目前設定的工作表：

- 學生名單：工作表 gid `0`，取第一欄的班級座號。
- 題目資料：工作表 gid `2028107386`，依欄位「卷號」、「題號」、「內容」整理各卷題數。

如更換工作表分頁或欄位名稱，請同步更新 `index.html` 的 `SOURCES` 與欄位辨識邏輯。

## 部署前的存取與隱私檢查

已確認預計公開部署，任何網站訪客都能查看目前表格中的班級座號清單。公開網站上的瀏覽器程式必須取得學生名單，因此訪客也能檢視來源資料。不要在前端加入 API 金鑰或服務帳戶憑證。

寫入端點位於 `Code.gs`，部署為 Apps Script 網頁應用程式，以擁有者身分執行並允許所有人呼叫。端點只寫入指定「對錯紀錄」工作表的 A:D 欄，並檢查欄位標題和 0/1 答案值。網站訪客可從名單選學生，不代表已驗證學生身分；任何知道公開網址的人都能提交或更新名單中的作答紀錄。端點網址設定在 `index.html` 的 `WRITE_ENDPOINT`。
